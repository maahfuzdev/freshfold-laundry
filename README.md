## 📌 Project Overview

**Smart Laundry** is a cutting-edge, full-featured laundry management system that bridges the gap between customers and service providers. This modern web application offers a seamless experience with real-time order tracking, dynamic pricing, integrated payment solutions, and comprehensive admin analytics.

### 🎯 Key Highlights
- 🚀 **Real-time Order Tracking** - Live status updates for every order
- 💰 **Dynamic Pricing System** - Automatic bill calculation based on services
- 📱 **Mobile Wallet Integration** - bKash & Nagad payment support
- 📊 **Advanced Analytics** - Visual charts for business insights
- 🔐 **Secure Authentication** - Firebase-powered user management
- ⚡ **Instant Notifications** - Real-time updates via Firebase
